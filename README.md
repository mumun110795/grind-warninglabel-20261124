## The entry

> WARNING: Runs on 2 hours of sleep and total confidence. May say 'I'm fine' while malfunctioning. Do not let near a send button after midnight.

One line (142 characters), written in genuine safety-label register — a
`WARNING:` header, a "May…" side-effect clause, and a "Do not let near…"
instruction — wrapped around a flaw everyone recognises: the human who is
running on almost no sleep, is completely sure everything is under control,
will insist "I'm fine" while visibly malfunctioning, and must be kept away
from a send button after midnight before a message goes out that cannot
be unsent.

## Run it

```sh
node main.ts
```

This writes the line as UTF-8 text to `entry.txt` inside the output
directory: `process.env.OUTPUT_DIR` when set, otherwise `/output`.
